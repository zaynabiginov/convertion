# Convertion.uz

Конвертер валют и прогноз погоды для Узбекистана и других городов.

[English](README.md) | [Русский](READMEru.md) | [O‘zbekcha](READMEuz.md)

## Возможности

- Перевод между узбекским сумом (UZS) и поддерживаемыми валютами по курсам Центрального банка Республики Узбекистан.
- Карточки валют с поиском, история курсов, графики и статистика за выбранный период.
- Сравнение курсов покупки и продажи коммерческих банков с фильтрами, поиском и сортировкой.
- Текущая погода, почасовой прогноз и прогноз на 7 дней. Для каждого дня доступны данные на утро, день, вечер и ночь.
- Поиск города и определение местоположения. При загрузке погодного блока браузер запросит разрешение на геолокацию.
- Русский, узбекский и английский языки, светлая и тёмная темы.

## Запуск локально

Запускайте сайт через HTTP-сервер, а не открывайте `index.html` напрямую. В Windows выполните из папки проекта одну из команд:

```powershell
py -m http.server 8000
# Если Python Launcher недоступен:
python -m http.server 8000
```

Откройте в браузере [http://localhost:8000](http://localhost:8000). Установка пакетов и сборка не требуются.

Геолокация доступна на сайтах с HTTPS и на localhost. Разрешите доступ к местоположению в запросе браузера. Если разрешение отклонено или координаты недоступны, будет показан прогноз для Ташкента. Попробуйте определить местоположение кнопкой ещё раз или найдите город вручную. Координаты используются для запроса прогноза и определения названия города через Open-Meteo.

## Конвертер валют

1. Введите сумму и выберите исходную и целевую валюты. Списки валют можно искать по названию или коду.
2. Результат пересчитывается автоматически. Кнопка со стрелками меняет направление обмена.
3. Найдите валюту в карточках курсов ЦБ и выберите сумму. Нажмите на карточку, чтобы посмотреть историю курса.
4. В таблице коммерческих банков доступны фильтры по банку, валюте, типу курса и диапазону цен, а также сортировка по заголовкам. Покупка и продажа указаны со стороны банка: при покупке иностранной валюты у банка сравнивайте **Продажу**, при продаже валюты банку — **Покупку**.
5. В окне истории выберите даты или готовый период, изучите значения на графике, измените масштаб и просмотрите статистику.

Выбранные язык и тема сохраняются в текущем браузере.

## Погода

Погодный раздел встроен на главную страницу; его также можно открыть отдельно по адресу `weather/index.html`. Он показывает текущие условия, прогноз на ближайшие 24 часа и на 7 дней. Для каждого дня отображаются температура, ощущаемая температура, ветер, влажность, давление, световой день, восход и закат, УФ-индекс и фаза Луны. Прогноз геомагнитного индекса Kp предоставляет NOAA, если данные доступны.

Кнопка местоположения позволяет повторить запрос геолокации. Если не разрешать доступ, сайт продолжит показывать погоду для Ташкента; другой город можно найти через поиск. Геолокация может быть недоступна при открытии страницы как локального файла `file://` или с небезопасного нелокального адреса.

## Источники данных

- Центральный банк Республики Узбекистан — официальные курсы валют и история курсов.
- Bank.uz — курсы покупки и продажи в коммерческих банках.
- Open-Meteo — поиск мест и прогноз погоды.
- NOAA Space Weather Prediction Center — прогноз геомагнитного индекса Kp.

Для загрузки курсов и погоды нужен интернет. Источники могут быть временно недоступны; данные Kp могут отсутствовать для отдельных дней прогноза.

## Подготовка статической публикации

Проект не требует пакетов для запуска. Чтобы подготовить статический сайт с актуальными курсами банков, историей курсов ЦБ и погодным разделом, выполните:

```powershell
python scripts/prepare-pages.py --output .\pages-output
```

Выходная папка должна быть новой или пустой. Скрипт загружает данные и собирает файлы сайта; содержимое выходной папки можно опубликовать на статическом хостинге. Используйте HTTPS, чтобы браузер мог предоставить сайту геолокацию.

Обработчики из `api/` предназначены для серверless-хостингов, поддерживающих серверные функции. GitHub Pages такие обработчики не запускает.
